Hermes-Lite 2.x
===============

请参阅主要的 [Hermes-Lite 网页](http://www.hermeslite.com) 获取最新链接和详情。

这是一个正在进行的项目，旨在基于 [宽带调制解调器芯片](http://www.analog.com/en/broadband-products/broadband-codecs/ad9866/products/product.html) 和 [Hermes SDR](http://openhpsdr.org/wiki/index.php?title=HERMES) 项目，创建一款低成本的软件定义业余无线电 HF 收发信机。
