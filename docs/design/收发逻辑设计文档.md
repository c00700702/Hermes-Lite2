## 1. 系统总体架构

Hermes-Lite 2 是一台基于 AD9866 SDR 收发芯片 + Ethernet PHY 的 HF 软件定义无线电。
FPGA 内部可以划分为 **网络域（下游/上游）**、**射频域（AD9866 采样域）** 两大部分，
接收与发射的数据流在这两个域之间通过异步 FIFO 跨越时钟域。

```
                     PC (SDR Console / PowerSDR / qsdr 等)
                              │  UDP (OpenHPSDR protocol)
        ┌─────────────────────┴──────────────────────────┐
        │                network (ethernet/)             │
        │   rgmii_recv → mac_recv → ip_recv → udp_recv   │  ← 网络接收(下行数据包)
        │   udp_send  → ip_send  → mac_send → rgmii_send │  → 网络发送(上行数据包)
        └──────┬───────────────────────────▲─────────────┘
      ethrxint │ (PC→卡 数据)         ethtxint│ (卡→PC 数据)
        ┌──────▼──────────┐       ┌───────────┴────────┐
        │ dsopenhpsdr1    │       │ usopenhpsdr1       │
        │ (下游协议解包)   │       │ (上游协议打包)      │
        └──┬─────┬────────┘       └────────▲─────▲─────┘
   dseth_tdata  │cmd              usiq_fifo │   │ usbs_fifo(rx_data)
        ┌───────▼────────┐                  │   │
        │ dsiq_fifo      │(CDC 8bit→36bit)  │   │
        └───────┬────────┘                  │   │
 ad9866 clk     │ tx_tdata(I/Q+PTT)         │   │ rx_tdata(24bit I/Q)
  ┌─────────────▼───────────────────────────┴───┴───────────────┐
  │                        radio (radio_openhpsdr1/radio.v)     │
  │  ┌─────────────── 发射链 TX ──────────────┐                 │
  │  │ TX状态机→FirInterp8_1024→CicInterpM5   │                 │
  │  │ →cpl_cordic(NCO上变频)→预失真/PWM→DAC   │                 │
  │  └────────────────────────────────────────┘                 │
  │  ┌─────────────── 接收链 RX ──────────────┐                 │
  │  │ mix2(NCO下变频)→receiver_nco:          │   ◄── rx_data   │
  │  │ cic→varcic→firX8R8 → 多通道复用上传     │                 │
  │  └────────────────────────────────────────┘                 │
  └───────────────▲───────────────────────────┬─────────────────┘
                  │ rx_data(12bit ADC)         │ tx_data(12bit DAC)
        ┌─────────┴────────────────────────────▼────────┐
        │            ad9866.v (LVDS 串并转换接口)        │◄──► AD9866 芯片引脚
        └───────────────────────────────────────────────┘
                              │
        control.v (SPI/I2C 配置 AD9866、慢ADC、PTT/KEY、LED、保护)
```

要点：

- **接收方向（RX）**：天线 → AD9866 ADC → `ad9866.v`（LVDS 解串）→ `radio.v` 内多个 `mix2 + receiver_nco` 数字下变频/抽取 → 上游复用状态机 → `usiq_fifo`（跨时钟域）→ `usopenhpsdr1.v`（协议打包）→ `network` UDP 发送 → PC。
- **发射方向（TX）**：PC IQ 音频 → `network` UDP 接收 → `dsopenhpsdr1.v`（协议解包）→ `dsiq_fifo`（跨时钟域）→ `radio.v` 内 TX 状态机 → `FirInterp8_1024` + `CicInterpM5` 内插 → `cpl_cordic` 数字上变频 → 预失真/包络 PWM → `ad9866.v`（LVDS 串行化）→ AD9866 DAC → PA → 天线。
- 命令通道（频率、控制寄存器）由 `dsopenhpsdr1` 解出后以 `cmd_addr/cmd_data/cmd_rqst` 广播给 `ad9866`、`radio`、`control` 三个命令从设备。

## 3. 公共基础设施（收发共用）

### 3.1 顶层组织：`hermeslite_core.v`

`hermeslite_core` 用 generate 参数裁剪功能，与收发直接相关的参数：

```verilog
parameter NR = 4;        // 接收机数量（决定 radio 内 mix2/receiver_nco 实例个数）
parameter NT = 1;        // 发射机数量（0 则完全不生成 TX 逻辑）
parameter LRDATA = 0;    // 下行音频通道用途: 0=不用, 1=TX预失真表, 2=TX包络PWM(EER)
parameter HL2LINK = 0;   // 多板级联同步
parameter DSIQ_FIFO_DEPTH = 16384;  // 发射样本 FIFO 深度
```

关键连线（发射方向）：

```verilog
// hermeslite_core.v —— 下游 I/Q 进入 dsiq_fifo（网络域 → AD9866 域）
dsiq_fifo #(.depth(DSIQ_FIFO_DEPTH)) dsiq_fifo_i (
  .wr_clk(clock_ethrxint), .wr_tdata({dsethiq_tuser,dseth_tdata}),
  .wr_tvalid(dsethiq_tvalid), .wr_tlast(dsethiq_tlast),
  .rd_clk(clk_ad9866),     .rd_tdata(dsiq_tdata),
  .rd_tvalid(dsiq_tvalid), .rd_tready(dsiq_tready), ...);

// radio 的 TX 流接口：36bit = {tuser[3:0], I高8,I低8,Q高8,Q低8}
.tx_tdata ({dsiq_tdata[7:0],dsiq_tdata[16:9],dsiq_tdata[25:18],dsiq_tdata[34:27]}),
.tx_tuser ({dsiq_tdata[8],dsiq_tdata[17],dsiq_tdata[26],dsiq_tdata[35]}),
.tx_tvalid(dsiq_tvalid), .tx_tready(dsiq_tready), .tx_twait(dsiq_twait),
.tx_data_dac(tx_data),                       // → ad9866 DAC
```

关键连线（接收方向）：

```verilog
// radio 的 RX 流接口 → usiq_fifo（AD9866 域 → 网络上送域）
.rx_data_adc(rx_data),
.rx_tdata(rx_tdata), .rx_tvalid(rx_tvalid), .rx_tready(rx_tready),
.rx_tlast(rx_tlast), .rx_tuser(rx_tuser),

usiq_fifo #(.AK4951(AK4951)) usiq_fifo_i (
  .wr_clk(clk_ad9866), .wr_tdata(rx_tdata), .wr_tuser(rx_tuser), ...
  .rd_clk(clock_ethtxint), .rd_tdata(usiq_tdata), ...);

// 频谱(bandscope)原始 ADC 走 usbs_fifo
usbs_fifo usbs_fifo_i (.wr_clk(clk_ad9866), .wr_tdata(rx_data), ...
                       .rd_clk(clock_ethtxint), .rd_tdata(bs_tdata), ...);
```

### 3.2 命令总线（收发共享的配置通道）

`dsopenhpsdr1` 从下游包中解析出 6bit 地址 + 32bit 数据：

```verilog
SYNC0:  ds_cmd_mask_next = eth_data[1:0];          // 通道掩码
CMDCTRL: begin
  ds_cmd_resprqst_next = eth_data[7];              // 是否需要响应
  ds_cmd_addr_next     = eth_data[6:1];            // 6bit 寄存器地址
  ds_cmd_ptt_next      = eth_data[0];              // ★ PTT 位（发射开关）
end
CMDDATA3..0: 依次拼出 32bit 数据，最后 ds_cmd_cnt 取反发出脉冲
```

`cmd_cnt` 经 `sync_pulse` 变成三域脉冲 `cmd_rqst_io / cmd_rqst_ad9866 / cmd_rqst_dsopenhpsdr1`，
`ad9866`、`radio`、`control`、`localaudio` 都作为命令从设备监听同一 `cmd_addr/cmd_data`。
其中 **地址 0x01 = TX 频率**，**0x02~0x16 = RX1~RX12 频率**，**0x00 bit2 = duplex**、**bit16 = pa_mode(EER)** 等，详见 §9。

### 3.3 CDC 同步器（`cdc_sync.v` / `sync.v`）

- `sync`：两级触发器，同步伪静态电平（如 `ds_cmd_ptt`→`ds_cmd_ptt_ad9866sync`）。
- `sync_pulse`：把快域翻转脉冲安全转到慢域（命令请求、`ds_pkt_cnt` 回告）。
- `sync_one`：窄脉冲（≥1 慢周期）跨域展宽捕获（`qmsec_pulse`、`msec_pulse`）。

这些实例集中出现在 `hermeslite_core.v` 的 "Downstream ethrxint clock domain"、
"Upstream ethtxint clock domain"、"AD9866 clock domain" 三节中。

## 4. 接收（RX）链路设计与代码详解

接收链路自模拟前端向后分为 5 级：**ADC 解串 → 数字下变频(mix2) → 信道抽取(receiver_nco) → 多通道复用上传 → 协议打包发送**。

### 4.1 物理层网络接收（PC 命令/响应通路的前半段）

虽然严格说这是"网络接收"，但它是接收控制流入口，列于此以便理解闭环：

- `rgmii_recv.v`：用 DDIO (`ddio_in.v`) 把 RGMII 的 DDR nibble 还原为 4bit `phy_rx` + `phy_rx_dv`。
- `mac_recv.v`：帧定界、目的 MAC 过滤、CRC32 校验（`crc32.v`），输出字节流。
- `ip_recv.v`：剥 IP 头，只放行 UDP。
- `udp_recv.v`：按端口分流，输出 `udp_rx_active/udp_rx_data` 与 `to_port/broadcast`——这正是 `dsopenhpsdr1` 的输入。

### 4.2 AD9866 LVDS 接收解串：`ad9866.v`（RX 部分）

AD9866 以 LVDS 双线（A/B）× 6bit、在内部 `rxclk` 上按 2 个半周期交替送出 I/Q 各 12bit。
FPGA 在 `clk_2x`（122.88MHz）上重采样并用 `rxsync` 帧头组装：

```verilog
always @(posedge clk_2x) begin
  rffe_ad9866_rx_d1 <= rffe_ad9866_rx;          // 打一拍消除亚稳态
  rffe_ad9866_rx_d2 <= rffe_ad9866_rx_d1;
  rffe_ad9866_rxsync_d1 <= rffe_ad9866_rxsync;  // sync 也延迟对齐
  if (rffe_ad9866_rxsync_d1)
    rx_data_assemble <= {rffe_ad9866_rx_d2, rffe_ad9866_rx_d1}; // {后半,前半}=12bit
end
always @ (posedge clk) rx_data <= rx_data_assemble;  // 回到 clk(61.44M) 域
assign rffe_ad9866_mode = 1'b1;                      // LVDS 模式
```

**过载检测**（供 AGC/指示灯/上报）：

```verilog
assign rxclipp   = (rx_data == 12'b011111111111);   // 满幅正
assign rxclipn   = (rx_data == 12'b100000000000);   // 满幅负
assign rxgoodlvlp= (rx_data[11:9] == 3'b011);       // ≈ -3dBFS 判定
...
if (rxclrstatus) rxclip <= 1'b0;                    // 由 control 定期清除
if (rxclipp | rxclipn) rxclip <= 1'b1;
```

**FAST_LNA 快速增益**（HL2 特色）：收到 0x0A/0x0E 命令后，在 TX/RX 切换点利用
`txsync` 空闲窗口把 PGA5 位随 LVDS 流写出，实现收发切换瞬间完成 LNA 切换：

```verilog
if ((rx_gain != gain) & (~tx_en | ...)) begin gain <= rx_gain; update_gain <= 1'b1; end
...
rffe_ad9866_tx <= tx_data_d1[11:6];
rffe_ad9866_pga5 <= pga5_d1;           // 借用 TX 数据线传 PGA 设置
```

### 4.3 ADC 分发与下变频：`radio.v` + `nco/mix2.v` + `nco/nco2.v`

`radio.v` 先把 ADC 数据打一级寄存扇出到最多 5 路（改善布线/时序扇出）：

```verilog
always @ (posedge clk) begin
  adcpipe[0] <= rx_data_adc;  adcpipe[1] <= rx_data_adc; ... adcpipe[4] <= rx_data_adc;
end
```

每个物理 ADC 输入用一个 `mix2` 产生 **两路不同本振的中频 I/Q**（乘法器时分复用，节省 DSP）：

```verilog
mix2 #(.CALCTYPE(CALCTYPE)) mix2_0 (
  .clk(clk), .clk_2x(clk_2x), .rst(rst_nco | &tx0_phase_zero),
  .phi0(rx0_phase), .phi1(rx_phase[2]),      // 两个 NCO 步进字
  .adc(adcpipe[0]),
  .mixdata0_i(mixdata_i[0]), .mixdata0_q(mixdata_q[0]),   // → receiver_0
  .mixdata1_i(mixdata_i[2]), .mixdata1_q(mixdata_q[2]));  // → receiver_2
```

PureSignal 校准复用：RX2 的本振在发射校准时改锁 TX DAC 数据（自环）：

```verilog
.adc((tx_on & pure_signal) ? tx_data_dac : adcpipe[1]),
```

`mix2.v` 内部：`nco2` 在 `clk_2x` 上以半周期交替推进 phi0/phi1 两个角度；
`sincos` 给出 19bit 正余弦，做符号-幅度转换后与 12bit ADC 经流水线乘法器相乘，
结果舍入截断为 18bit，并按 `state`（clk_2x 每拍翻转）分别写入通道 0/1 输出寄存器：

```verilog
nco2 nco2_i (.state(state), .clk_2x(clk_2x), .phi0(phi0), .phi1(phi1), .cos(cos), .sin(sin));
mult_ABOpiped imult (.a({{6{adc[11]}},adc}), .b(scos_q), .o(i_data_d)); // I = x·cos
mult_ABOpiped qmult (.a({{6{adc[11]}},adc}), .b(ssin_q), .o(q_data_d)); // Q = x·sin
assign i_rounded = i_data_d[28:11] + {17'h00,i_data_d[10]};             // 右移11位+舍入
always @(posedge clk_2x)
  if (state) begin mixdata0_i <= i_rounded; mixdata0_q <= q_rounded; end
  else         begin mixdata1_i <= i_rounded; mixdata1_q <= q_rounded; end
```

`nco2.v`（双相位累加器）：

```verilog
always @(posedge clk_2x) begin
  if (state) begin angle1 <= angle0 + phi1; angle0 <= rst ? 0 : angle1; end
  else       begin angle1 <= angle0 + phi0; angle0 <= rst ? 0 : angle1; end
end
sincos sincos_i (.angle(angle1[31:12]), ...);   // 用高位角度查表
```

### 4.4 单接收机信道化：`receiver_nco.v`

每个逻辑接收机 = **固定 CIC → 可变 CIC → 多相 FIR** 三级抽取，采样率演进：

```
61.44 MHz --cic(÷CICRATE=5)--> 12.288 MHz --varcic(÷rate=2..40)--> 6.144..0.3072 MHz
          --firX8R8(再÷8)--> 48k ~ 384 ksps 输出 I/Q (24bit) + out_strobe
```

```verilog
// 第一级：3 阶固定 CIC（宽度按 CICRATE 参数化防溢出）
cic #(.STAGES(3), .DECIMATION(CICRATE), .IN_WIDTH(18), .ACC_WIDTH(ACCWIDTH), .OUT_WIDTH(16))
  cic_inst_I2(.clock(clock), .in_strobe(1'b1), .out_strobe(decimA_avail),
              .in_data(mixdata_I), .out_data(decimA_real));
// 第二级：5 阶可变 CIC，decimation 来自 PC 速率命令(48k→40, 384k→5)
varcic #(.STAGES(5), .IN_WIDTH(16), .ACC_WIDTH(VARCICWIDTH), .OUT_WIDTH(16))
  varcic_inst_I1(.in_strobe(decimA_avail), .decimation(rate),
                 .out_strobe(decimB_avail), .in_data(decimA_real), .out_data(decimB_real));
// 第三级：8 相多相 FIR（抗镜像+通带平坦），输出即最终样本
firX8R8 fir2 (.x_avail(decimB_avail), .x_real(...), .x_imag(...),
              .y_avail(out_strobe), .y_real(out_data_I2), .y_imag(out_data_Q2));
```

辅助模块细节：

- `cic.v`：generate 循环级联 `cic_integrator`（降采样前积分）与 `cic_comb`（抽取后差分），
  `out_strobe` 每 DECIMATION 个输入产生一次。
- `varcic.v`：`sample_no == decimation-1` 时出样；按 decimation 的 2/3/4/6/8/12/16/24/40 组合
  选择截位窗口（GROWTH 位增长补偿），保证输出恒为 16bit。
- `firfilt.v` 的 `firX8R8`：把 8 个分支乘加分时完成，24bit 累加器
  `Racc/Iacc` 分 8 拍合并，`wstate==8` 时拉高 `y_avail`；系数 ROM `fir256`（`firromH.v`）
  与样本 RAM（`firram36.v`）配合支持 976 抽头。
- `REGISTER_OUTPUT`（HL2LINK 时用）：把 FIR 输出打一拍，便于跨板时序收敛。

`radio.v` 中共实例化 `receiver_0 … receiver_9`（受 NR 裁剪），每个对应一对
`mixdata_i/q[c]`，输出存入数组 `rx_data_i[]/rx_data_q[]/rx_data_rdy[]`。

### 4.5 VNA 接收旁路：`vna_scanner.v`

VNA FPGA 扫描模式下，通道 0 的正常接收机被替换：

```verilog
assign rx_data_rdy[0] = VNA_SCAN_FPGA ? vna_strobe : rx0_strobe;
assign rx_data_i[0]   = VNA_SCAN_FPGA ? vna_out_I  : rx0_out_I;
vna_scanner rx_vna(.freq_delta(rx_phase[0]), .tx_freq_in(tx_phase0),

```

它直接消费 `mix2_0` 的 18bit 输出做窄带积分，得到幅相用于网扫。

### 4.6 多通道复用上传状态机（`radio.v` 下半部）

`rxus_state` 状态机把所有已启用通道（`chan ≤ last_chan`，由 0x00 命令 bit[6:3] 设定）
的 I、Q 依次弹出，写入 `usiq_fifo`，格式为 24bit 数据 + tuser(clip 标志) + 每轮末尾 tlast：

```verilog
RXUS_WAIT1: if (rx_data_rdy[0]) ... rxus_state_next = RXUS_I;   // 以 ch0 就绪为整轮节拍
RXUS_I:  rx_tvalid=1; rx_tdata=rx_data_i[chan_index]; → RXUS_Q
RXUS_Q:  rx_tvalid=1; rx_tdata=rx_data_q[chan_index];
         chan==last_chan ? (rx_tlast=1 → RXUS_WAIT0) : (chan+1 → RXUS_I)
RXUS_WAIT0: 等待 ch0 strobe 落下，防止丢样
```

HL2Link 扩展态：`RXUSLM_I/Q`（Master 把 Slave 传来的样本插入上轮流）、
`RXUSLS_I/Q`（Slave 把自己的样本经串口链路 `ls_valid/ls_done` 交给 Master）。

### 4.7 上游协议打包：`usopenhpsdr1.v`

`ethtxint` 域的发送状态机（START/WIDE*/DISCOVER*/UDP*/SYNC_RESP/RXDATA*/MIC*/PAD）：

- `UDP1/UDP2`：构造 0x02 响应包（长度 1032B）：`ef fe 02 02 <seqno>` + **4 字节响应**
  （`resp`，含 clip、温度、TX 缓冲水位等）+ 最多 12 通道 × 2(I/Q) × 256 样本的 IQ 轮数据
  + 每通道 2 字节 mic/clip 位（`MIC1/MIC0`，来自 `us_tuser`）+ PAD。
- 数据弹出节奏：`RXDATA2/1/0` 逐字节输出 `us_tdata[23:16]/[15:8]/[7:0]`，并在 `RXDATA0`
  执行 `us_tready = 1'b1` 真正从 FIFO 取下一个样本——**网络发包速度必须 ≥ 样本产生速度**，
  否则 `usiq_fifo` 满、`radio` 侧 `rx_tready` 拉低丢弃该轮（协议允许丢帧）。
- 序列号 `ep6_seq_no` 每包 +1；`wide_spectrum` 打开时先走 WIDE1..4 频谱包（`bs_tdata` 12bit→每 2 样本 3 字节）。
- 若一轮样本未凑齐但需要发包，用 `round_bytes` 判断补 PAD(0xff)。

### 4.8 接收辅助：AGC/指示/侧音

- `control.v`：聚合 `rxclip/rxgoodlvl` 进 0x02 响应；驱动 `io_led_adc75/100`；
  定期发 `rxclrstatus` 脉冲清过载锁存。
- `localaudio.v`（AK4951 变体）：把接收/侧音数字音频经 `i2s_ak4951.v` 送到本地耳机。

## 5. 发射（TX）链路设计与代码详解

发射链路自 PC 向前分为 6 级：**下游协议解包 → dsiq_fifo → TX 状态机 → 内插滤波(FIR+CIC) → CORDIC 上变频+修正 → DAC 串行化输出**。

### 5.1 下游 I/Q 解包（`dsopenhpsdr1.v` PUSH* 状态）

PC 的 0x04/0x06 数据包中，每 6 字节一组 `L1 L0 R1 R0 I1 I0`（实际只用 I/Q）：

```verilog
PUSHI1: begin
  dsethiq_tuser  = ds_cmd_ptt;            // ★ 首字节 tuser 携带命令包带来的 PTT
  dsethiq_tvalid = ds_cmd_ptt | cwx_pushiq;
  state_next = PUSHI0; end
PUSHI0: begin
  dsethiq_tuser  = cwx_saved[0];          // CWX 键控位（内部键控器模式）
  ...
PUSHQ0: begin
  dsethiq_tvalid = ds_cmd_ptt | cwx_pushiq;
  dsethiq_tlast  = 1'b1;                  // 每组 4 样本结束
  if (&pushcnt[5:0]) ... state_next = SYNC2;   // 256 样本/包
  else state_next = PUSHL1;               // 继续下一样本
```

注意 `dsethiq_tvalid` 只在 `ds_cmd_ptt`（PTT=1 的数据包）或 CWX 挂起期才写入 FIFO——
**没有 PTT 时收到的 I/Q 一律丢弃**，保证发射起点干净。
8bit 数据流 `dseth_tdata` 与 1bit `dsethiq_tuser` 一起写入 `dsiq_fifo`，
FIFO 读出侧组成 36bit `{tuser, 4×byte}`，即一次读出一个 16bit I + 16bit Q + 标志。

### 5.2 发射缓冲 FIFO：`fifos.v :: dsiq_fifo`

- 写 9bit×16384 / 读 36bit×4096 的混合宽度 DCFIFO（`dcfifo_mixed_widths`，showahead）。
- **准入控制**：`allow_push` —— FIFO 写满后丢弃后续数据，直到某个包的 `wr_tlast`
  且水位低于 `wrlimit`(4KB≈20ms) 才恢复，配合上位机 20ms 突发节奏。
- **水位上报**：`rd_sample`（由 `control` 产生的采样脉冲）锁存 `rd_tlength` 高 7bit 成
  `rd_status={recovery, level}`，经 `control→resp` 回给 PC 做 TX 缓冲遥测；`ds_wait`
  （=`dsiq_twait`，PRETX 停顿指示）也上报。
- 读出使能 `rd_tready` 完全由 `radio` 的 TX 状态机掌握（见下）。

### 5.3 TX 运行状态机（`radio.v` Transmitter code）

输入约定：`tx_tuser[1]=CWX keyup, [2]=CWX keydown, [3]=PTT`；
另有外部硬件信号 `ext_keydown`（面板/CW 键）、`ext_ptt`、`ds_cmd_ptt`。

```verilog
NOTX : begin                       // 待机
  tx_fir_i_next=0; tx_fir_q_next=0; tx_cwlevel_next=0;
  tx_qmsectimer_next = {tx_buffer_latency,2'b00};  // 预置启动延时计时
  tx_on = 1'b0;
  // 释放上次残留样本，保持磁带模式时间连续
  accumdelay_decr = ~fir_tready;  tx_tready = accumdelay_notzero | fir_tready;
  if (ext_keydown|ext_ptt|cwx_keydown|cwx_keyup|(ds_cmd_ptt&ptt)) tx_state_next = PRETX;
end

PRETX : begin                      // 建立期：停止消费样本，让FIFO积累 tx_buffer_latency
  tx_twait = 1'b1;  tx_tready = 1'b0;
  accumdelay_incr = fir_tready;    // 统计积累的样本数
  if (ext_keydown & ext_ptt) ... tx_state_next = CWTX;
  else if (tx_qmsectimer != 0) begin            // 0.25ms 递减计时
    if (qmsec_pulse) tx_qmsectimer_next = tx_qmsectimer - 1;
    if (~(key|ptt...)) tx_state_next = NOTX;    // 提前放弃则回退
  end else begin                                 // 计时到 ⇒ 正式开台
    if (ext_keydown) tx_state_next = CWTX;
    else if (ptt)    tx_state_next = PTTTX;     // 数据驱动的SSB/CW(软键)
    else if (cwx_keydown|cwx_keyup) tx_state_next = CWTX;
    ...
  end
end

PTTTX : begin                      // 正常发射（SSB/AM/数字/CW软键）
  if (ext_keydown) tx_state_next = CWTX;
  else if (ptt_hang_saturated & ~ds_cmd_ptt) tx_state_next = NOTX; // 急停
  else if (ptt) begin
    tx_qmsectimer_next = {2'b00, ptt_hang_time, 2'b00};  // PTT撤销后的尾巴计时
    if (fir_tready) begin tx_fir_i_next = tx_tdata[31:16];
                          tx_fir_q_next = tx_tdata[15:0]; end  // ★ 消费一个IQ样本
  end else begin                   // PTT已撤：排空缓冲或超时退出
    if (timer) dec; else if (~ptt_hang_saturated) tx_state_next = NOTX;
  end
end

CWTX : begin                       // 硬键/ CWX 发射：生成渐变CW载波
  cw_on=1; tx_cw_key=1;
  if (key down) begin                       // 按下：幅度斜坡上升
    if (tx_cwlevel != MAX_CWLEVEL) tx_cwlevel_next = tx_cwlevel + 1; ...
  end else begin                            // 释放：下斜坡 + hang
    ... else tx_state_next = CWHANG;
  end
end
CWHANG : begin ... 保持 cw_on 直到 hang 结束回 NOTX end
```

设计意图小结：

- `tx_on` 拉高后才使能 `ad9866` 的 DAC LVDS 输出与 `txquiet_n`、T/R 切换（`pa_inttr/pa_exttr`、`rffe_rfsw_sel` 由 `control.v` 根据 `tx_on/cw_on` 同步切换）。
- `tx_buffer_latency`（0x17 命令可设，默认 20ms）+ `PRETX` 积累 ⇒ 发射起始有足够样本，避免内插滤波器起步瞬态。
- `cw_profile = tx_cwlevel` 同时输出给 `localaudio` 做侧音强度曲线。

### 5.4 采样率内插链：`FirInterp8_1024` + `CicInterpM5`

```verilog
// 48ksps I/Q → ×8 FIR 内插 → 输出 y1_r/y1_i (20bit)，req 节奏向状态机要新样本
FirInterp8_1024 fi (clk, req2, fir_tready, tx_fir_i, tx_fir_q, y1_r, y1_i);
// ×RRRR(=200 @76.8MHz) CIC 内插 → 达到全时钟率
CicInterpM5 #(.RRRR(RRRR), .IBITS(20), .OBITS(16), .GBITS(GBITS)) in2
   (clk, 1'd1, req2, y1_r, y1_i, y2_r, y2_i);
// 总内插比 8×200=1600：48k × 1600 = 76.8M ✓
```

- `FirInterp8_1024`：经典"零填充等效"多相结构——输入样本写 RAM（128 深），
  每次 `calc` 触发用一组错位系数（C0,C8,C16… → C1,C9,…）算一个输出，8 个输出后 `req`
  请求下一输入；`firram36I_1024.v`/`firrom/firromI_1024.v` 提供存储。
- `CicInterpM5`：先 ×RRRR 插零（单点非零），4 级积分-梳状，输出截位含 DC spur 校正；
  `GBITS=log2(R^M)` 归一化增益。
- 两者串联实现 48k→76.8M 的无镜像重建，radio.v 注释中的增益预算说明整体 ≈1.0
  （0.61×0.992×0.4117×4）。

### 5.5 数字上变频：`cpl_cordic`（复数 CORDIC NCO）

```verilog
// CW 时以固定幅度喂入，SSB 时用内插输出；I/Q 交换以选对边带
assign tx_i = vna ? 16'h4d80 : (tx_cw_key ? {1'b0, tx_cwlevel[18:4]} : y2_i);
assign tx_q = (vna | tx_cw_key) ? 16'h0 : y2_r;

cpl_cordic #(.OUT_WIDTH(16)) cordic_inst (
  .clock(clk), .frequency(tx0_phase),        // TX 相位字（0x01 命令换算而来）
  .in_data_I(tx_i), .in_data_Q(tx_q),
  .out_data_I(tx_cordic_i_out), .out_data_Q(tx_cordic_q_out));

assign txsum  = (tx_cordic_i_out >>> 2);     // 增益调整后可直接给 DAC
assign txsumq = (tx_cordic_q_out >>> 2);
```

原理（代码注释原文）：复正弦相乘只产生和频 `exp(jf1)·exp(jf2)=exp(j(f1+f2))`，
因此基带 I/Q 被线性搬移到 `tx0_phase` 对应的中频（HL2 中频约 6.5MHz，最终混频在
AD9866 内部完成）。CORDIC 采用象限预旋转 + 19 级迭代（`atan_table`），
`frequency==0` 时相位与其它 CORDIC 同步复位以保证相干。

TX 频率字来源与 RX 相同（§6.1）：`tx_phase0` 由 0x01 命令的 Hz×M2 计算，
VNA 扫描时被 `tx0_phase` 递增替代。

### 5.6 DAC 前的三种输出模式（`case (LRDATA)`）

**模式 0 – 直通**：

```verilog
always @(posedge clk) tx_data_dac <= txsum[11:0];
```

**模式 1 – TX 预失真（PD1）**：PC 通过下行"音频"通道（`dslr_fifo`）持续写入两张
4096×13bit 查找表 `DACLUTI/DACLUTQ`（幅度/相位非线性校正），然后：

```verilog
assign distorted_dac = DACLUTI[txsumr2[11:0]] - DACLUTI[txsumqr2[11:0]]
                     + DACLUTQ[iplusq_over_root2r[12:1]];
case (tx_predistort[1:0]) 0: tx_data_dac <= txsum[11:0];
                          1: tx_data_dac <= distorted_dac[11:0]; endcase
```

（`iplusq/√2` 用移位加法近似；两级打拍对齐表读延迟；开关由 0x2B 命令 bit[17:16]。）

**模式 2 – EER/ET 包络 PWM（EER1）**：与主链并行，对同一 I/Q 流做 ×5 FIR 内插
（`FirInterp5_1025_EER`）后用 `square`+`sqroot` 求包络 √(I²+Q²)：

```verilog
counter counter_inst (.clock(clk_envelope), .q(ramp));   // 245.76MHz 下 1024 计数=240kHz 锯齿
wire [14:0] envelope_scaled = envelope + (envelope>>>2)+(envelope>>>3); // ×1.375
always @(posedge clk_envelope)
  PWM <= (ramp < PWM_min | envelope_level > ramp) && ramp < PWM_max;    // 比较调宽
assign tx_envelope_pwm_out     = (tx_on & pa_mode) ? PWM : 1'b0;        // pa_mode=EER使能(0x00 bit16)
assign tx_envelope_pwm_out_inv = ~tx_envelope_pwm_out;                  // 差分互补驱动包络电源
```

`PWM_min/max` 可由 0x11 命令在线调整；包络电源由 `control.v` 的 `pwr_envpa/envop/envbias` 上电时序控制。

### 5.7 DAC LVDS 串行化：`ad9866.v`（TX 部分）

```verilog
always @(posedge clk_2x) begin
  tx_en_d1 <= tx_en;  tx_sync <= ~tx_sync;
  if (tx_en_d1) begin
    if (tx_sync) begin tx_data_d1 <= tx_data;
                       rffe_ad9866_tx <= tx_data_d1[5:0]; end   // 低6bit + sync 半拍
    else              rffe_ad9866_tx <= tx_data_d1[11:6];       // 高6bit
    rffe_ad9866_txsync <= tx_sync;
  end else begin rffe_ad9866_tx <= 6'h00; rffe_ad9866_txsync <= 1'b0; end
end
assign rffe_ad9866_txquiet_n = tx_en_d1;   // 非发射时 DAC 静噪（降低杂散噪声）
```

`tx_en = tx_on & ~atu_txinhibit_ad9866sync`（ATU 调谐期间强制禁发）；
HALFDUPLEX 编译选项下还有 TX/RX 共用 6 对差分线的半双工版本。

### 5.8 发射周边控制

- **T/R 切换**：`control.v` 将 `tx_on_iosync/cw_on_iosync` 同步后驱动
  `rffe_rfsw_sel`、`pa_inttr/pa_exttr`（含消抖的 PTT 输入 `ext_ptt`、`io_tx_inhibit` 并入）。
- **CWX 硬件键控**：`iambic.v` 对 tip/ring paddle 消抖后产生 Iambic-B 元素，
  经 `control.v` 转成 `cw_keydown` 脉冲（`cwx_keydown/keyup` 也可走 PC 回环或由
  `dsopenhpsdr1` 的 `cwx_pushiq` 注入 I/Q 流 tuser）。
- **看门狗**：`dsopenhpsdr1` 中 `watchdog_cnt` 在 run 且收到包清零，连续 ~2s 无包则
  强制 `run=0, ds_cmd_ptt=0`，TX 状态机回 NOTX——防止 PC 死机时电台一直发射。
- **extamp.v**：PTT 时向 Elecraft 功放串口发送 `FA<freq>;` 自动选频段。
- **usopenhpsdr1**：把 `dsiq_status`（FIFO 水位）与 `ds_wait` 编入 0x02 响应，PC 据此
  调节推送速率（"磁带模式"流控闭环）。

## 6. 频率合成与 NCO/CORDIC 公共数学模块

### 6.1 频率字计算（`radio.v`）

PC 发来 Hz（32bit），FPGA 就地换算为 32bit 相位增量：

```verilog
localparam M2 = (CLK_FREQ==76800000) ? 32'd1876499845 : ...;  // 2^57/OSC 截取
assign freqcomp = cmd_data * M2 + M3;                          // +M3 实现四舍五入
// CMD_FREQ 状态机打 3 拍后：
freqcompp[0] <= freqcomp[56:25];                               // 取 32bit 相位字
```

地址→NCO 索引映射（`nco_index`）：0x01→TX(4'hf)、0x02→RX1(0)…；
HL2Link 主从模式下还有 `synced_receivers` 参与的双播映射（同频接收机共享相位）。
半双工时 RX0 自动跟随 TX 频率（`rx_phase[0] <= tx_phase0`）。

### 6.2 RX 与 TX NCO 的两套实现

| 用途 | 模块 | 结构 | 位置 |
|------|------|------|------|
| RX 下变频 | `nco2`+`sincos` | 相位累加→查表(粗+细+乘法) | `rtl/nco/` |
| TX 上变频 | `cpl_cordic` | 相位累加→CORDIC 旋转（自带 NCO） | `radio_openhpsdr1/` |
| 旧版/备用 | `cordic`(实信号), `nco1`+`mix1`/`mixtx1` | 同类思想 | 同上 |

`sincos.v` 的 `CALCTYPE`：0=细表 ROM（精度最高）；1/2/3=用乘法/逻辑在线算 sin(fine)
（省 M9K，牺牲 SFDR）；`mixtx1.v` 展示了一次复乘的标准展开
`I' = I·cos − Q·sin, Q' = I·sin + Q·cos`（qs1r/radioberry 变体使用）。

## 7. 跨时钟域与数据流汇总

| 数据 | 源域 | 宿域 | 载体 |
|------|------|------|------|
| PC→IQ 样本 | clock_ethrxint | clk_ad9866(61.44M) | `dsiq_fifo` |
| 预失真/包络音频 | ethrxint | clk_ad9866 | `dslr_fifo` |
| RX I/Q | clk_ad9866 | clock_ethtxint | `usiq_fifo` |
| 频谱 ADC | clk_ad9866 | clock_ethtxint | `usbs_fifo` |
| 命令 addr/data | ethrxint | ad9866/ctrl/ethtx | 伪静态 + `sync_pulse(cmd_cnt)` |
| PTT/run/key | 各域 | 目标域 | `sync` 两级 |
| msec/qmsec 脉冲 | clk_ctrl/ad9866 域 | 其它域 | `sync_one` |
| 水位/clip 状态 | ad9866 域 | ctrl(2.5M)/ethtx | `sync` + resp 寄存器 |

时钟来源：`ethpll`（125M/90°/25M/12.5M/2.5M）与 `ad9866pll`
（61.44M=clk、122.88M=clk_2x、245.76M=clk_envelope、慢速计量时钟），

## 8. 典型工作时序流程（端到端）

### 8.1 接收一次"轮"的过程

1. AD9866 每 1/61.44ms 送出 12bit ADC → `ad9866.v` 组装 `rx_data`。
2. `mix2_0` 用 `rx0_phase` 混频出 ch0/ch2 的 18bit I/Q（`clk_2x` 每拍交替）。
3. `receiver_nco` 三级滤波，`out_strobe` 到达设定速率（48ksps 时每 1280 拍一次）。
4. `rxus` 状态机等 `rx_data_rdy[0]`，依次弹出 last_chan+1 个通道的 I、Q 写 `usiq_fifo`，末样本置 tlast。
5. `usopenhpsdr1` 在 UDP2 判定待发（凑满一轮），逐字节出包 → `network` → PC。
6. 同时 `usbs_fifo` 的原始 ADC 若 wide_spectrum 开启则打包频谱包。

### 8.2 从按下 PTT 到 RF 出现

1. PC 在命令包 CMDCTRL 置 `ds_cmd_ptt=1`，随后每个数据包的 I1 字节 tuser=1。
2. `dsopenhpsdr1` PUSH 状态把 `{tuser,data}` 写 `dsiq_fifo`；`ds_cmd_ptt` 经 sync 到 ad9866 域。
3. `radio` TX FSM：NOTX→PRETX，`tx_twait=1`（上报 PC 暂停推流），积累 `tx_buffer_latency`。
4. 计时到 → PTTTX：开始按 `fir_tready` 消费样本 → FIR×8 → CIC×200 → `cpl_cordic` 上变频 → `tx_data_dac`。
5. `tx_on=1` → `ad9866.v` 打开 LVDS 发送与 `txquiet_n`；`control.v` 切 T/R、点亮 TX LED、（可选）ATU/PA 使能、extamp 发频段命令。
6. 撤 PTT：FSM 排空尾巴样本（`ptt_hang_time`）后回 NOTX；急停命令（hang=31）立即关闭。

### 8.3 CW（硬键）流程

`ext_keydown`（面板键或 iambic 输出）→ PRETX（若已在 TX 则直接 CWTX）→ CWTX 用
`tx_cwlevel` 斜坡生成恒定幅度矢量 `(level, j0)` → CORDIC 输出单音载波 → 释放后
下斜坡 + `cw_hang_time` 延展（CWHANG）→ NOTX。侧音曲线 `cw_profile` 同步给 localaudio。

## 9. 附录

### 9.1 主要命令地址（radio/ad9866/control 共享 cmd 总线）

| 地址 | 方向 | 含义（与收发相关） |
|------|------|--------------------|
| 0x00 | 写 | bit[25:24] 采样率(48k..384k→`rate`)、bit[6:3] last_chan、bit[2] duplex、bit[16] pa_mode(EER) |
| 0x01 | 写 | TX 频率 Hz → `tx_phase0` |
| 0x02–0x16 | 写 | RX1–RX12 频率 → `rx_phase[n]` |
| 0x09 | 写 | VNA 使能/扫描点数 |
| 0x0A | 写 | RX LNA/增益（FAST_LNA 解析） |
| 0x0E | 写 | TX 增益覆盖 |
| 0x0F | 写 | bit24 使能内部 CWX |
| 0x10 | 写 | cw_hang_time |
| 0x11 | 写 | PWM_min/PWM_max（包络 PWM） |
| 0x17 | 写 | tx_buffer_latency(bit6:0)、ptt_hang_time(bit12:8) |
| 0x2B | 写 | 预失真开关 sub-index |
| 0x39 | 写/读 | PS 控制、调试、HL2Link 主从、synced_receivers |

### 9.2 主要参数（76.8MHz 时钟变体）

```
CICRATE = 5      // 第一级 CIC 抽取 61.44M→12.288M（clk 为 76.8M 晶振的 4/5 派生）
RRRR    = 200    // TX CIC 内插倍率（×8 FIR = 1600，48k→76.8M）
RATE48  = 40     // varcic 抽取（48ksps），96k=20, 192k=10, 384k=5
DSIQ_FIFO_DEPTH = 16384 字（≈80ms @48ksps 双字节 I/Q）
```

### 9.3 变体差异速览

- `hl2b3to4_cicrx / hl2b5up_cicrx`：RX 仅 CIC（省 FIR，宽带模式）。
- `hl2b5up_4000`：CLK_FREQ=79.872M（CICRATE=13, RRRR=208）。
- `hl2b5up_ak4951v3/v4`：AK4951=1，本地音频收发（`localaudio`，tuser 扩为 16bit 音频）。
- `hl2b5up_bypassversa`：不使用 VersaClock。
- `radioberry_*`：树莓派 SoC 接口版（`pi-pio/rx_pi_pio.v`、`tx_pi_pio.v` 承担收/发并行总线，`juice/` 为新版 Juice 协议核心，内部同样是 `usopenhpsdr1/dsopenhpsdr1 + radio + ad9866ctrl` 结构）。
